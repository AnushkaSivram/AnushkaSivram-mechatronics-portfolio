# Reusable Payload-Bay Deployment Mechanism

This is a simulation-only model of a low-energy, spring-actuated payload-bay door latch. It avoids propulsion, pyrotechnics, and flight operation details. The model tracks a torsion-spring door under hinge friction and aerodynamic-like opposing load to assess opening time and seating margin.

Run `python3 simulate.py` to create `deployment_response.csv`.
